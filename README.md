## 一。确保程序可以正常运行

### 第一步：下载 Python

1. 打开浏览器，访问网址：[https://www\.python\.org/](https://www.python.org/)

2. 点击页面上的黄色按钮 "Download Python 3\.x\.x"（版本号可能不同）

3. 下载完成后，双击打开安装包（\.exe 文件）

### 第二步：安装 Python

1. 打开安装包后，**一定要勾选** "Add Python to PATH" 选项（非常重要！）

2. 点击 "Install Now" 开始安装

3. 等待安装完成，看到 "Setup was successful" 即可关闭安装程序

### 第三步：验证 Python 安装

1. 按键盘上的 Windows 键 \+ R 键，输入 "cmd" 后按回车

2. 在黑色窗口中输入：`python --version` 然后按回车

3. 如果显示版本号（如 Python 3\.x\.x），说明安装成功

### 第四步：安装必要的库

1. 按 Windows 键 \+ R 键，输入 "cmd" 按回车打开命令提示符

2. 依次输入以下命令并按回车（每个命令执行完再输下一个）：

```Plain Text
pip install pytesseract
pip install mss
pip install pillow
pip install keyboard
```

### 第五步：下载并安装 Tesseract OCR 引擎

1. 访问：[https://github\.com/UB\-Mannheim/tesseract/wiki](https://github.com/UB-Mannheim/tesseract/wiki)

2. 点击 "tesseract\-ocr\-setup\-\*\.exe" 下载安装包

3. 双击安装，选择安装路径（记住安装位置，通常是 C:\\Program Files\\Tesseract\-OCR\\）
**记得在安装过程中选择将 Tesseract 添加到系统 PATH**（我自己下载的时候没有看到这个选项，如果你也没有的话看第六步）

4. 安装完成后**不要重启**

### 第六步：手动添加 Tesseract 到系统 PATH

1. 按 Windows 键，搜索 "环境变量"，点击 "编辑系统环境变量"

2. 在 "系统属性" 窗口中，点击 "环境变量" 按钮

3. 在 "系统变量" 区域找到 "Path"，点击 "编辑"

4. 点击 "新建"，输入 Tesseract 的安装路径，例如：
`C:\Program Files\Tesseract-OCR`

5. 点击确定保存所有设置

6. 重启电脑

### 第七步：验证 Tesseract 安装

1. 重启电脑后，按 Windows 键 \+ R 键，输入 "cmd" 按回车

2. 输入：`tesseract --version` 按回车

3. 如果显示版本信息，说明安装成功

### 第八步：运行您收到的程序文件

1. 收到 "Level flight bombing trajectory \[computer\.py\]\(computer\.py\)" 文件后，将其保存到桌面

2. 按 Windows 键 \+ R 键，输入 "cmd" 按回车

3. 输入：`cd Desktop` 按回车

4. 输入：`python "Level flight bombing trajectory computer.py"` 按回车

5. 程序开始运行，悬浮窗口会出现在屏幕上

### 备选方式（使用 PyCharm IDE）（我自己是用这个方案的，因为我是从头开始写代码的，没有试过上面第八步的方法）

如果您更习惯使用 IDE，可以：

1. 下载并安装 PyCharm 社区版

2. 在 PyCharm 中打开 "Level flight bombing trajectory \[computer\.py\]\(computer\.py\)" 文件

如果你在运行的过程中报错了，可以用 pycharm 里面自带的通义灵码直接问，或者把错误码复制到网页版通义灵码再询问。

## 二．调整参数

### （一）调整航弹参数

默认是 1000lb\_anm65a1（海盗王和 AD4 用的那款 1000 磅航弹，其他飞机也有用这款炸弹的，可以去战雷里自己看），可以根据航弹的拆包数据自己修改。

GitHub 地址：gszabi99/War\-Thunder\-Datamine
路径：aces\.vromfs\.bin\_uz—\> gamedata—\> weapons—\> bombguns，里面是各种各样航弹的拆包数据。

需要提取 `mass`、`caliber`（用来算 S）、`dragCx`，填入代码里对应的位置。

参数计算规则：

- m = mass（拆包内质量数值）

- S = π × \(d/2\)²，d 为拆包 caliber 数值

- Cd = dragCx

- g 固定为 9\.81 不变

### （二）OCR 识别区域调整

原理：这个程序是基于屏幕 OCR，对特定屏幕区域截图识别数字后完成投弹计算。代码内包含三组 OCR 识别区域参数，均为字典格式，包含 4 个像素参数：

1. top：截图区域上边界距离屏幕顶部像素

2. left：截图区域左边界距离屏幕左侧像素

3. width：截图区域横向总像素宽度

4. height：截图区域纵向总像素高度

#### 1\. 游戏设置前置修改

- 先开启气压高度 \+ 雷达高度显示

- 将空中载具参数文字颜色改为蓝色，大幅提升 OCR 识别成功率

#### 2\. 坐标测量方法
[安装使用教程.docx](https://github.com/user-attachments/files/30705385/default.docx)

1. 游戏内完整截图界面（微信截图快捷键 Ctrl\+A）

2. 打开在线屏幕坐标工具网页，粘贴截图测量像素

3. 分别测量**雷达高度、飞行速度、实际海拔高度**三组数字区域的四角坐标，换算出 top/left/width/height 填入代码

#### 测量注意事项

截图时保证海拔、雷达高度显示 4 位数字，速度显示 3 位数字；若经常超 1000km/h，按 4 位数字预留识别区域，避免识别截断。

#### 坐标换算示例

海拔高度数字四角坐标：
左上 X:247 Y:101 \| 右上 X:325 Y:101
左下 X:247 Y:135 \| 右下 X:325 Y:135
换算结果：Top:101，Left:247，Width:78，Height:34

## 三．测试

全部配置完成后启动程序，悬浮窗口默认置顶显示，将窗口挪至屏幕侧边，不要遮挡游戏 HUD 数字识别区域。

进入战争雷霆游戏后，窗口会实时刷新雷达高度、空速、实际海拔数值；窗口内**斜距 L**为当前平飞状态下炸弹理论落点距离。
例：斜距 L=2000m，代表距离目标 2000 米时投弹可命中目标附近；实战需要预留提前量，高度越高所需提前量越小。
补充：炸弹挂载位置偏外侧时，轰炸需要额外修正偏航误差。

### 故障排查

窗口数值无显示、识别误差大：

1. 核对 Python、Tesseract 环境是否完整安装并配置 PATH

2. 重新测量游戏 HUD 像素坐标，修正 OCR 识别区域参数

3. 确认游戏参数文字为蓝色、无窗口遮挡识别区域

## 最后说明

该工具仅基于物理模型做粗略弹道计算，未纳入气温、气流等环境变量；但足以满足战区轰炸需求，稍加练习可保证炸弹落点贴近目标。
精准轰炸核心难点是获取自身与目标的实时距离，当前仅能依靠目视 / 小地图估算；俯冲轰炸实战效率仍高于平飞投弹。
